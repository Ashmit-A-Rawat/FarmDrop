FarmDrop is a mobile application developed using Flutter for the Smart India Hackathon (SIH) 2024. The app aims to connect farmers directly with consumers and retailers, facilitating the sale of agricultural produce without intermediaries.

Key Features:

Produce Listings: Farmers can create detailed listings of their products, including descriptions, quantities, and pricing.

Direct Negotiations: The platform enables direct communication between farmers and buyers, allowing for price negotiations and personalized agreements.

Transaction Management: Integrated tools assist in managing orders, payments, and delivery logistics, ensuring a seamless transaction process.

User-Friendly Interface: Designed with simplicity in mind, the app offers an intuitive interface accessible to users with varying levels of technical expertise.

Technologies Used:

Flutter: For cross-platform mobile application development.

Firebase: Utilized for backend services, including authentication, real-time database, and cloud storage.

RESTful APIs: To facilitate communication between the app and external services.
