# 🌾 FarmDrop – Smart Agriculture Marketplace

**FarmDrop** is a mobile application developed using **Flutter** and **Firebase**, aimed at transforming the agricultural ecosystem by connecting **farmers** and **buyers** on a unified platform. The app facilitates smarter trade, communication, and learning — all tailored to modern agricultural needs.

## 📱 Features

### 🔐 Authentication
- **Login/Signup** with role-based access
- Two user roles: **Farmer** and **User**

---

### 👨‍🌾 Farmer Panel

- 🛒 **Product Listing**  
  Add and manage available crops/products with pricing and quantity.
  
- 🌦️ **Weather & Pest Alerts**  
  Real-time weather updates and pest warnings to support planning.

- 📈 **Demand Trends**  
  Insights into market demands and trends based on crop data.

- 📚 **Farmer Education**  
  Access learning resources in **multiple languages** to empower farmers.

- 🎁 **Offers**  
  View offers by customers directly.

- 💬 **Inbox**  
  Chat with users and buyers for direct communication.

- 👤 **Profile**  
  View and edit farmer information and preferences.

---

### 🛍️ User Panel

- 🛒 **Shop**  
  Browse and buy directly from farmers.

- 🤝 **Negotiation Portal**  
  Request custom deals or negotiate pricing with farmers.

- 💬 **Inbox**  
  Directly message farmers about listings and logistics.

- 👤 **Profile**  
  Manage user account details and order preferences.

## 📌 Project Goals

- Bridge the gap between **farmers** and **urban buyers**.
- Provide **real-time intelligence** to support agricultural decision-making.
- Encourage **direct trade** to benefit both ends of the ecosystem.
- Promote **agricultural education and literacy** in rural areas.

> 🏆 Developed as part of the **Smart India Hackathon (SIH) 2024**.
